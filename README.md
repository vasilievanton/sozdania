# СоздАния — кликабельный прототип (v3)

Каркас платформы по ТЗ v2.0, синхронизированный с реальным расписанием релизов
(1 июня — 5 июля).

## Главное в этой версии

- **Один режим, один пользователь.** Нет переключения «ребёнок ↔ родитель».
  Контент для родителей — отдельные пункты в общем меню (Материалы, Сессии,
  Релакс, Карточка дня).
- **Контент открывается по расписанию.** На карте, в районах и в режиме 3 видно:
  что доступно сегодня (5 июня по умолчанию), что откроется позже, что уже
  закрылось.
- **Совместные задания — это тесты и карточки.** Главное — тест «Какие мы
  напарники?», ребёнок и родитель проходят независимо, на выходе получают
  знаменитый дуэт (Тимон и Пумба, Чебурашка и Гена и т.п.).
- **Придумкино.** Графический редактор удалён. Внутри района — раскраски
  готовых шаблонов + общая галерея граффити (загружают извне). Открывается
  с 22 июня.
- **Технодром.** 4 робота с разным графиком: Доставщик (с 1 июня),
  Уборщик (с 6 июня), Самокатер (с 12 июня), Садовник (15–21 июня, сезонная).
- **Удалён экран ошибки домена** — некритично для прототипа.

## Открыть

Двойной клик по `index.html` — главный экран с выбором трёх режимов.

## Три режима

### Режим 1 — `sitemap.html`
Все экраны прототипа списком, для проверки полноты.

### Режим 2 — UX-тур (10 шагов)
Линейный сценарий за родителя Ивана и его ребёнка Машу (9 лет, группа 6–9):
регистрация → ребёнок → карта → Технодром → игра «Уборщик» → результат →
Материалы → Тест «Какие мы напарники?» → Лидерборд.

### Режим 3 — `games.html`
Расписание всех релизов по неделям, сгруппированное по районам и разделу для
родителей. Видно: что когда открывается, какие есть заметки, что уже закрылось.
